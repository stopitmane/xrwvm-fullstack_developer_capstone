# Quick Start Guide

## Run These Commands in Order:

### 1. Setup (First Time Only)
```cmd
cd xrwvm-fullstack_developer_capstone
setup_environment.bat
```

### 2. Build Frontend
```cmd
build_frontend.bat
```

### 3. Start Server
```cmd
start_server.bat
```

### 4. Access Application
Open browser: `http://localhost:8000`

## Key URLs:
- Home: `http://localhost:8000/`
- Dealers List: `http://localhost:8000/dealers`
- Dealer Details: `http://localhost:8000/dealer/<id>`
- Post Review: `http://localhost:8000/postreview/<id>`
- Login: `http://localhost:8000/login`
